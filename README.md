# 📊 Mapa Conceptual: Libre Cambio vs Proteccionismo

## Descripción
Este repositorio contiene un mapa conceptual comprehensivo sobre teoría comercial internacional, analizando las posiciones del **libre cambio** y el **proteccionismo**, así como un análisis balanceado de ambas perspectivas.

## 📋 Contenidos

### 1. **LIBRE CAMBIO** 🎯
- Fundamentos clásicos (Smith, Ricardo)
- Ventaja absoluta y comparativa
- Críticas y defensas históricas
- Teorías modernas (Heckscher-Ohlin, Krugman)
- Comercio intra-industrial

### 2. **PROTECCIONISMO** 🛡️
- Estructuralismo latinoamericano (CEPAL, Prebisch)
- Tesis Prebisch-Singer
- Industrialización por Sustitución de Importaciones (ISI)
- Argumento de la industria naciente
- Política comercial estratégica

### 3. **BALANCE Y CONCLUSIONES** ⚖️
- Virtudes del libre cambio
- Costos del proteccionismo excesivo
- Asimetrías estructurales
- Articulación de políticas comerciales e industriales
